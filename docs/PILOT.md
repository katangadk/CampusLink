# Small student pilot

Do not mark this complete from automated checks. No students have been invited
by the assistant. Use fictional profiles for the preview; invite consenting
adult students with real information only after the owner accepts the verified
eligibility/privacy process and operational arrangements.

Start with a small agreed cohort, such as 6–10 consenting adults across at least
two programs. Explain public likes, private comments, who can see posts, read
receipts, staff access, account deletion and the preview's limitations. Do not
ask people to share passwords or IDs in feedback. Make withdrawal easy. An
operator must be available during the exercise.

Have participants independently create an account, receive owner approval,
confirm email and finish the configured student/adult checks. Observe whether
they can find a profile from another program, understand public Like versus
private Comment, opt into Dating, make a mutual match, exchange messages and
use the safety footer. Test one poor-connection retry and one background/resume
cycle. Observe rather than coach through each step; record where help was
needed. Do not manufacture mutual interest or send messages on their behalf.

| Observation | Record |
| --- | --- |
| Date, deployed commit, device/browser/network | Pending |
| Participants consented and eligibility checked | Pending |
| Account/approval/email/checks completed without help | Pending |
| Cross-program discovery and public Like understood | Pending |
| Private comment acceptance understood | Pending |
| Mutual match creates one conversation | Pending |
| Messages/receipts/retry/background-resume work | Pending |
| Safety actions and withdrawal understood | Pending |
| Biggest confusion, bugs and requested changes | Pending |

Members can send **Profile → Send feedback**. The owner can triage and resolve
these privately in the operator console. Maintain a short issue list with the
reproducible step, impact, owner and retest result. A saved screenshot is not
proof a connection or message worked. Fix lost/duplicate messages, privacy
failures, inaccessible controls and failed eligibility before adding more
participants. Repeat the affected journey after fixes, then decide with the
participants whether the app is useful enough to expand.
